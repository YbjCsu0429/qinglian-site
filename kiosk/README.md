# 馆内导览机 · 部署与操作手册

这套方案让廉洁教育馆的电脑**开机自动全屏打开网站**，访客直接触摸或点击，不需要联网，不需要域名。

---

## 一、第一次部署（约 5 分钟）

1. 把整个 `site` 文件夹复制到馆内电脑，例如 `D:\廉洁导览\site`
   > 路径**不要带空格和特殊符号**，避免脚本出错
2. 确认电脑装有 **Chrome 或 Edge**（两者之一即可）
3. 双击 `kiosk\启动导览.bat` —— 应立即进入全屏导览界面
4. 双击 `kiosk\1-安装开机自启.bat` —— 之后开机登录会自动启动
5. 重启电脑验证一次

---

## 二、日常使用

| 场景 | 操作 |
|---|---|
| 开机 | 自动进入导览，无需操作 |
| 访客使用 | 轻触/点击屏幕任意处 → 进入首页 |
| 无人时 | 150 秒无操作自动回到欢迎页 |
| 想换台电脑 | 整个文件夹拷过去，重复第一步 |
| 临时停止 | 双击 `停止导览.bat` |
| 恢复 | 双击 `启动导览.bat` |

---

## 三、怎么退出导览（给管理员）

**方法一（推荐）**
按 `Win + D` 回到桌面 → 双击 `停止导览.bat`。

**方法二（Wi n 键被锁时）**
按 `Ctrl + Alt + Del` → 打开任务管理器 → 结束所有 `Google Chrome` 进程 → 再运行 `停止导览.bat`。

**方法三（隐藏手势）**
在屏幕**左上角 72 像素内快速连点 5 次**，输入管理密码 `2026`，会退出导览。
> 密码在 `assets/js/app.js` 的 `initKiosk()` 里，搜索 `2026` 即可改。

## 四、更新内容

所有文字都在 `site\assets\js\data.js`：

- 加文章 → 往 `ARTICLES` 里加一条
- 加人物 → 往 `FIGURES` 里加一条
- 改情景 → 改 `SCENARIOS`
- 让廉洁AI 更聪明 → 往 `KB` 里加问答条目

改完保存，按 `F5` 刷新即可生效（或重启导览）。

⚠️ 改之前建议先复制一份 `data.js` 备份。改错了浏览器按 `F12` 会显示具体行号。

## 五、建议做的系统设置

到馆内电脑上逐项检查：

1. **电源**：控制面板 → 电源选项 → 关闭“睡眠”和“关闭显示器”（脚本已尝试自动设置，但可能被系统策略覆盖）
2. **通知**：设置 → 系统 → 通知 → 关闭，避免弹窗盖在导览界面上
3. **Windows 更新**：设置 → 更新 → 活动时间设为全天，避免演示中途重启
4. **自动登录**：设置 → 账户 → 若需要开机直接进桌面，可配置自动登录（需管理员）
5. **缩放**：显示设置 → 缩放建议 100%–125%，最大 150%，超过会导致排版变化
6. **分辨率**：1920×1080 及以上最佳

## 六、常见问题

**Q：双击启动后一闪而过，没反应？**
A：多半是没装 Chrome/Edge。装一个再试。脚本会优先用 Chrome，没有则用 Edge。

**Q：提示“无法打开此文件”/ 被安全软件拦截？**
A：右键 `启动导览.bat` → 属性 → 解除锁定；或在杀毒软件里把 `site` 文件夹加入信任。

**Q：访客按 Alt+F4 关掉了怎么办？**
A：脚本会在 2 秒后自动重新打开——这是有意设计的。

**Q：黑屏/白屏？**
A：检查 `site\index.html` 是否存在、文件夹是否被移动。路径含中文一般没问题，含空格可能出问题。

**Q：想换成竖屏一体机？**
A：直接可用，页面会自适应。但首页在窄屏下会变成单列，建议先在设备上试看，需要专门调整竖屏版式可以再改。

**Q：需要让访客用手机扫码看？**
A：当前方案是本地单机，手机访问需要额外配置局域网服务（固定内网 IP + 二维码），需要时再扩展。

## 七、为什么要本地，不要域名

| | 本地导览机 | 公网域名 |
|---|---|---|
| 断网 | ✅ 照常运行 | ❌ 打不开 |
| 费用 | 0 | 域名 + 服务器/托管 |
| 备案 | 不需要 | 绑国内服务器需要 |
| 稳定性 | 取决于这台电脑 | 取决于网络与平台 |
| 维护 | 拷文件夹 | 每次改动要重新上传 |

结论：**馆内展示不需要域名。** 域名只在两种情况下才有意义：访客要在馆外用自己手机看，或者你要把链接写进结题材料当长期成果。后者建议用 Gitee Pages（见 `site/DEPLOY.md`），两者可以并存——本地版给馆内，线上版给材料。

---

## 八、答辩时怎么讲这个设计

一句话：**“我们把数字产品做成了离线可用的导览终端，而不是一个依赖公网的网页。”**

展开三点：
1. 场馆网络不可控，离线运行保证了可用性；
2. 本地部署零成本、零备案，符合学生项目的资源约束；
3. 导览机模式（自动回到欢迎页、退出保护）本身是“数字科技助廉”的一部分——**技术服务于场景，而不是为了展示技术**。
