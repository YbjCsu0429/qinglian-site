# materials · 交付物

对外提交与现场使用的成品文件。**不需要修改**，需要重新生成时见 [../tools/README.md](../tools/README.md)。

| 文件 | 说明 | 用途 |
|---|---|---|
| `青廉筑梦_阶段任务完成情况报告.docx` | 6 页：封面 + 正文 4 页 + 3–5 分钟汇报提纲 | 提交大创任务、汇报 |
| `qr-code.png` | 纯二维码 | 海报、桌贴、PPT 插图 |
| `立牌-A5.png` | A5 立牌设计稿 | 打印后放在互动屏旁 |

---

## 打印规格

| 项 | 建议 |
|---|---|
| 尺寸 | A5 竖版（148 × 210 mm） |
| 纸张 | 250g 以上铜版纸，或亚克力立牌 |
| 打印设置 | **实际大小**，不要选"适应页面" |
| 二维码边长 | 不小于 4 cm |

---

## 版本核对

立牌底部印有网址。打印前**核对这行字是否与当前线上地址一致**：

```
ybjcsu0429.github.io/qinglian-site/
```

若不一致，说明是旧版，需重新生成：

```bash
python tools/make_qr.py <当前地址> --install
```
