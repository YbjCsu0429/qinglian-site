## 二、这周做这 2 件事

### ④ 让手机能扫（需要你本人操作）

手机扫不了你电脑里的文件，所以要一个公网地址。

1. 注册 [gitee.com](https://gitee.com) → **完成实名认证**（Pages 必须实名，审核一般 1 天内）
2. 新建仓库 `qinglian-site`，选**公开**
3. 把本文件夹里除 `kiosk\` 外的所有文件上传（`index.html` 要在仓库根目录）
4. 仓库 → 服务 → Gitee Pages → 分支 `master` → 启动
5. 拿到地址，形如 `https://你的名字.gitee.io/qinglian-site`

拿到地址后，在电脑上运行一次（把网址换成你的）：

```powershell
cd "C:\Users\boxiya\Documents\deepseek-harness\default-workspace"
python tools\make_qr.py https://你的名字.gitee.io/qinglian-site --install
```

它会自动更新站内二维码、生成新的立牌 `out\立牌-A5.png`。

### ⑤ 打印立牌

打印 `out\立牌-A5.png`，选「实际大小 / A5」，做成硬卡或亚克力立牌，放在互动屏右下角。
二维码边长不要小于 4 cm。

## 四、长期怎么维护（大创要跑一年）

### 内容更新

所有文字都在 `assets\js\data.js` 一个文件里：

| 改什么 | 找哪里 |
|---|---|
| 加文章 | `ARTICLES` |
| 加人物 | `FIGURES` |
| 改情景 | `SCENARIOS` |
| 加法规 | `RULES` |
| 让廉洁AI 更准 | `KB` |

改完保存 → 刷新页面即可。**改之前先复制一份 `data.js` 备份。**

### 建议的节奏（和你们的九廉任务对齐）

| 时间 | 做完什么就往站里加什么 |

**一廉一页面，做完就加。** 到结题时，网站本身就是一份可点开的成果目录。

### 每次更新后

1. 馆内电脑：替换文件 → 刷新（或重启导览）
2. Gitee：上传新文件 → 点「更新」重新部署
3. 二维码不用重做（除非网址变了）

## 五、三条判断标准

以后有人问你“这个网站到底有没有用”，别用“挺好的”回答。用这三条：

1. **可核查**：每个说法能不能点到出处？（所以我们才做检索式 AI，而不是会编答案的机器人）
2. **可复用**：把文件交给另一个同学，他能不能照着跑起来？
3. **可留痕**：三个月后回看，能不能看出改过什么、为什么改？（所以每次改 `data.js` 前先备份）

## 六、出问题先看这里

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击启动没反应 | 没装 Chrome/Edge | 装一个 |
| 全屏后黑屏 | 文件被移动 | 确认 `index.html` 与 `assets` 同级 |
| 扫描二维码打不开 | 网址是临时的 / Gitee 未更新 | 重新生成二维码 |
| 手机打开排版乱 | 缓存了旧版本 | 手机浏览器下拉刷新 |
| 页面文字全变了 | 改 `data.js` 时漏了逗号 | 按 F12 看报错行号，或还原备份 |
