# 07 · 馆内导览运行手册

面向现场值班人员。**不需要懂技术。**

---

## 1. 部署（一次性，约 5 分钟）

1. 把整个文件夹拷到馆内电脑，例如 `D:\廉洁导览`
   > 路径**不要有空格**
2. 确认装了 **Chrome 或 Edge**（有其一即可）
3. 双击 `kiosk\启动导览.bat` —— 应立即全屏进入欢迎页
4. 双击 `kiosk\1-安装开机自启.bat` —— 之后开机自动启动
5. **重启电脑验证一次**

---

## 2. 日常运行

| 场景 | 操作 |
|---|---|
| 开机 | 自动进入，无需操作 |
| 访客使用 | 轻触屏幕 → 进入首页 |
| 无人时 | 150 秒自动回到欢迎页 |
| 临时停止 | 双击 `kiosk\停止导览.bat` |
| 恢复 | 双击 `kiosk\启动导览.bat` |

---

## 3. 怎么退出（给管理员）

**方法一（推荐）**
按 `Win + D` 回桌面 → 双击 `kiosk\停止导览.bat`。

**方法二**
按 `Ctrl + Alt + Del` → 任务管理器 → 结束所有 `Google Chrome` → 再运行停止脚本。

**方法三（隐藏手势）**
屏幕**左上角 72 像素内连点 5 次** → 输入密码 `2026` → 退出。

> 改密码：打开 `assets/js/app.js`，搜索 `2026` 改掉即可。

---

## 4. 访客按 Alt+F4 关掉了怎么办？

**不用管。** 脚本会在 2 秒后自动重新打开——这是有意设计的。

---

## 5. 系统设置建议

到馆内电脑上逐项检查：

- [ ] **电源**：关闭"睡眠"与"关闭显示器"（脚本会尝试自动设置，但可能被系统策略覆盖）
- [ ] **通知**：设置 → 系统 → 通知 → 关闭，避免弹窗盖住界面
- [ ] **Windows 更新**：活动时间设为全天，避免演示中途重启
- [ ] **缩放**：显示设置 → 100%–125%，最多 150%
- [ ] **分辨率**：1920×1080 以上最佳
- [ ] **自动登录**：如需开机直接进桌面，需管理员配置

---

## 6. 内容更新后

馆内电脑与线上是**两份独立文件**：

1. 线上：推送后自动更新
2. 馆内：把新的 `index.html` 与 `assets/` 覆盖过去 → 重启导览

**二维码不用换**（除非网址变了）。

---

## 7. 故障处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击没反应 | 没装 Chrome/Edge | 装一个 |
| 提示"无法打开此文件" | 系统安全策略 | 右键 → 属性 → 解除锁定；杀毒软件加信任 |
| 全屏后白屏 | 文件被移动 | 确认 `index.html` 与 `assets` 同级 |
| 浏览器起不来 | 分辨率/显卡驱动 | 换 Edge 试；或降低分辨率 |
| 无法退出 | 找不到停止脚本 | 用 `Ctrl+Alt+Del` → 任务管理器 |
| 触摸没反应 | 触摸驱动 | 先用鼠标测试，确认是驱动问题 |

---

## 8. 断网时的表现

**馆内版本完全不依赖网络**，断网照常运行。
唯一受影响的是页面上的二维码——那是指向公网的，需要手机有网才能打开。

---

## 9. 备份

馆内电脑上的内容必须有一份异地备份：

- U 盘一份
- 网盘 / 微信收藏一份
- 代码仓库一份（`git clone` 即可恢复）

**恢复方式**：解压 → 双击 `启动导览.bat`，约 30 秒。
