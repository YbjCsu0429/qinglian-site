# 04 · 数据结构规范

所有数据存放在 `assets/js/data.js`，共 8 个顶层常量。
本文档定义每个字段的含义与约束，**新增内容前必须对照本表**。

---

## 通用约定

| 约定 | 说明 |
|---|---|
| `id` 唯一 | 全站范围内不重复，用于路由与引用 |
| 字符串引号 | 一律用单引号 `'...'`；正文内的双引号用中文引号 `“”` |
| 末尾逗号 | 数组最后一项**不要**加逗号，否则旧版浏览器可能报错 |
| 日期格式 | `2026.9—10`（中文间隔号，不用 `-`） |
| 不要在数据里写 HTML 标签 | 例外：正文块允许 `<strong>` 等少量标签 |

---

## 1. `SITE` —— 项目信息

```js
const SITE = {
  name: '青廉筑梦',
  sub: '廉洁知识导航',
  full: '青"廉"筑梦——基于廉洁教育馆的...',
  org: '中南大学',
  term: '2026.8 — 2027.3',
  leader: '苏重天',
  teacher: '孔志强',
  members: ['苏重天', '余伯俊', '孟泽通', '洪雨蝶', '陈承鑫'],
  qrUrl: 'https://ybjcsu0429.github.io/qinglian-site/',
  qrImg: 'assets/img/qr.png'
};
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` / `sub` | string | 站名与副标题 |
| `full` | string | 项目全称，用于页脚 |
| `term` | string | 执行周期 |
| `leader` / `teacher` / `members` | string / array | 团队信息 |
| `qrUrl` | string | **手机访问地址**；为空时首页不显示二维码区 |
| `qrImg` | string | 二维码图片路径 |

> 更换域名后必须同步 `qrUrl`，并重新生成 `assets/img/qr.png`。

## 2. `DIMS` —— 四维

```js
{ key: '理论深度学习', no: '维度一', desc: '...', jiu: ['场馆研学践廉', '专题讲堂育廉'] }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `key` | string | 维度名称（**与文章 `dim` 字段严格对应**） |
| `no` | string | 序号文案 |
| `desc` | string | 100 字以内说明 |
| `jiu` | string[] | 该维度下的九廉名称 |

---

## 3. `JIU` —— 九廉卡片

```js
{
  id: 'j1', no: '01', name: '场馆研学践廉',
  dim: '理论深度学习',
  carrier: '研学路线 · 讲解脚本 · 现场教学',
  owner: '苏重天', period: '2026.8—10',
  summary: '一句话说明',
  article: 'a1'          // 关联文章 id
}
```

| 字段 | 类型 | 约束 |
|---|---|---|
| `id` | string | `j1`–`j9` |
| `no` | string | 两位数字，`01`–`09` |
| `dim` | string | 必须是 `DIMS` 中某个 `key` |
| `article` | string | **必须指向 `ARTICLES` 中存在的 id**，否则首页卡片点进去 404 |

---

## 4. `ARTICLES` —— 文章

```js
{
  id: 'a1',
  title: '“五廉课堂”：把一座馆走成一堂课',
  dim: '理论深度学习',
  jiu: '场馆研学践廉',        // 可为 null
  tags: ['场馆研学', '路线设计'],
  minutes: 6,
  excerpt: '卡片上显示的两行摘要',
  body: [ { t: 'h2', c: '小标题' }, { t: 'p', c: '正文' } ],
  source: '依据《学生执行计划》整理。'
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `a` + 数字 |
| `dim` | string | 必须匹配 `DIMS.key` |
| `jiu` | string \| null | 通用知识类文章填 `null` |
| `tags` | string[] | 用于搜索与 AI |
| `minutes` | number | 预计阅读分钟数（整数） |
| `excerpt` | string | 60–90 字，卡片摘要 |
| `body` | Block[] | 正文块数组，见下 |
| `source` | string | 出处说明，显示在文章标题下 |

### 正文块（Block）

| `t` | 含义 | `c` 类型 | 渲染为 |
|---|---|---|---|
| `h2` | 二级标题 | string | `<h2>` |
| `h3` | 三级标题 | string | `<h3>` |
| `p` | 段落 | string | `<p>` |
| `ul` | 无序列表 | string[] | `<ul><li>` |
| `ol` | 有序列表 | string[] | `<ol><li>` |
| `quote` | 引用 | string | `<blockquote>` |
| `callout` | 提示框 | string | 带底色的强调块 |

**规则**：一篇 800–1500 字为宜；`h2` 每 300 字左右一个；重要结论用 `callout`。

## 5. `FIGURES` —— 人物事迹

```js
{ id: 'f1', name: '包拯', era: '北宋 · 999—1062', tag: '古代廉吏', seal: '包',
  brief: '一句话简介',
  body: ['第一段', '第二段', '第三段'],
  lesson: '给我们的启示' }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `seal` | string | **单个汉字**，显示为印章 |
| `tag` | string | 分类：`古代廉吏` / `革命传统` / `时代楷模` / `医者仁心` |
| `era` | string | 生卒年或朝代 |
| `body` | string[] | 3 段左右，每段 60–100 字 |
| `lesson` | string | 一句话启示，显示在底部 |

**史实要求**：生卒年、职务、事件必须准确；不确定的细节宁可删掉。

## 6. `SCENARIOS` —— 情景实训

```js
{
  id: 's1', idx: '01', title: '评优名额的天平', sub: '班级国家励志奖学金评定风波',
  scene: '情景背景（150–250 字）',
  roles: [{ n: '班长 林浩然', p: '你', v: '角色说明' }],
  info: ['每个人知道什么'],
  decisions: [{
    no: '决策点一', title: '宿舍里的那句“帮兄弟一把”',
    q: '提问',
    options: [{ t: '选项文字', level: 'good|mid|bad', r: '后果说明' }]
  }],
  rules: ['规则依据'],
  questions: ['复盘问题']
}
```

| 字段 | 约束 |
|---|---|
| `decisions` | 固定 3 个，选项固定 3 个 |
| `options[].level` | `good`（守住）/ `mid`（中间）/ `bad`（越界），决定结果框颜色 |
| `roles` | 4 个角色：你、候选人/当事人、旁观者、同事 |
| `info` | 4 条信息差，是情景张力的来源 |

> 修改选项会改变"选择画像"的统计逻辑，改动前请确认。

## 7. `RULES` —— 法规制度

```js
{ id: 'r1', name: '《中国共产党廉洁自律准则》', scope: '全体党员', tag: '党内法规',
  points: ['要点 1', '要点 2'], note: '补充说明' }
```

| 字段 | 说明 |
|---|---|
| `scope` | 适用对象 |
| `tag` | `党内法规` / `法律` / `行业规范` / `校纪` / `学术规范` / `职业伦理` |
| `points` | 3–5 条，**只写要点，不写条文编号**（避免引用错误） |
| `note` | 一句提醒，说明"以官方文本为准" |

## 8. `KB` —— 廉洁AI 知识库

```js
{ q: '什么是微腐败', a: '答案正文', tags: ['微腐败', '概念'], link: '#/article/a10' }
```

| 字段 | 说明 |
|---|---|
| `q` | 问题的规范化表述，**AI 直接把它当作答案标题显示** |
| `a` | 答案正文，100–200 字 |
| `tags` | **最关键**：决定命中率，应包含用户可能的多种说法 |
| `link` | 出处链接，指向文章/情景/法规/关于页 |

### 提升命中率的三个技巧

1. `tags` 里放同义词：「红包、礼金、回扣」而不是只放「红包」
2. 一个概念拆成多条：`什么是微腐败` 与 `微腐败有哪些表现`
3. 答案第一句给结论，后面再解释——AI 只显示一条，用户往往只看开头

## 9. `CREATIVE` —— 文创作品

```js
{ id: 'c2', type: '书签', title: '书签 · 出淤泥而不染',
  img: 'assets/img/wenchuang/bookmark-2.jpg',
  desc: '取周敦颐《爱莲说》……',
  tags: ['爱莲说', '莲花'] }
```

| 字段 | 说明 |
|---|---|
| `type` | `贴纸` / `书签` / `明信片` / `卡套`（决定筛选项） |
| `img` | 图片路径，统一放在 `assets/img/wenchuang/`，文件名用英文 |
| `desc` | 60–120 字，必须写清**出处**（哪句诗、哪个意象） |

**图片规范**：长边不超过 1100px，JPEG 质量 82，单张控制在 250 KB 以内。

---

## 10. `RESOURCES` —— 学习资源

```js
{ id: 'rs1', no: '一', title: '国家层面政策文件', lead: '一句话导语',
  items: [{ t: '文件名称', m: '发布机关 · 年份', d: '要点说明' }] }
```

| 字段 | 说明 |
|---|---|
| `no` | 中文序号（一、二、三……），显示为圆形徽章 |
| `lead` | 该节的导语，60 字左右 |
| `items[].m` | 元信息行，用 `·` 分隔 |
| `items[].d` | 100–150 字，**只写要点，不抄原文** |

---

## 11. `BOOKS` —— 推荐书目

```js
{ cat: '理论读本（10 本）', items: ['《书名》作者，出版社', ...] }
```

书单固定 6 类、共 50 本，与《AI 训练资料》一致。改书目时同步改 `cat` 里的数量。

---

## 12. 新增内容的检查清单

- [ ] `id` 是否与现有重复？
- [ ] `dim` 是否能在 `DIMS.key` 中找到？
- [ ] `JIU[].article` 指向的 id 是否存在？
- [ ] 中英文引号是否混用？
- [ ] 数组最后一项是否多了逗号？
- [ ] 刷新页面后是否正常显示、点击是否 404？
