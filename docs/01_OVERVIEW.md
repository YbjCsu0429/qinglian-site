## 2. 要解决的问题

项目体系完整，但成果长期停留在 Word 文档里：

- 材料可以打印、可以汇报，但**学生无法自主使用**
- 无法在廉洁教育馆现场**被访客触达**
- 九项任务彼此割裂，**没有统一入口**
- 每次汇报都要重新整理材料，**无法复用**

数字平台要解决的就是这四件事。

## 5. 三条设计原则

### 原则一：零依赖

纯 HTML / CSS / JS，**无框架、无构建步骤、无数据库、无后端**。

理由：场馆网络不可控，断网要能用；项目周期长，三年后要还能打开；
学生团队没有运维能力。

### 原则二：可核查

廉洁AI **只检索、不生成**。系统在 51 条知识中匹配最相关条目，并同时给出出处。

理由：廉洁领域对错误信息容忍度极低。宁可"不聪明"，也要"可被追溯"。

### 原则三：可迁移

整个目录 160 KB，可拷到 U 盘、可换任何静态托管，不改一行代码。

理由：托管平台会变、政策会变、域名会过期。**文件在，就永远能重新上线。**
